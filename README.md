# AS Consultoría

Landing page de consultoría para agentes inmobiliarios.

## Desarrollo

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Assets

Colocá estos archivos en `src/assets/`:

- `logo-as.png`
- `angeles-consultoria.jpeg`
- `video-presentacion.mp4` (opcional)

## Configuración

Editá links, precios y datos bancarios en:

`src/config/siteConfig.js`
